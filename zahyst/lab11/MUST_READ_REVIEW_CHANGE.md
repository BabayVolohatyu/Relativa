# Перед захистом ЛР11

Коміти і знімки вже в гілці `testing/lab11`. Звіт — [REPORT.md](REPORT.md).

Регламент знімає **3 бали**, якщо на захисті пояснення не твої, або якщо складається враження, що OpenAPI і workflow ти не можеш пояснити. Перед парою проговори вголос чотири абзаци нижче, без читання з екрана.

За плутанину Single Source of Truth з підходами API-first і code-first знімають **2 бали**.

## Що сказати

Один факт живе в одному файлі. Призначення і команди запуску — у кореневому README. Як долучитися — у `docs/developer/`. Чому система така — у SDD, ISD і двох ADR. Як викликати шлюз — лише в `docs/api/openapi.yaml`. Сторінка API цей файл показує, а не переписує. Якби поруч була ще Markdown-таблиця тих самих полів, вона б відстала від контракту, і збірка цього б не помітила.

API-first тут означає: контракт — це yaml. Сторінка Swagger і клієнт `sdk/client` зібрані з нього. Code-first було б навпаки: спочатку атрибути в C#, yaml народжується з них. Ми пішли від маршрутів, які вже є в шлюзі, записали їх у yaml і перевірили викликом. `GET /health` повернув `status=ok` і `service=relativa-gateway`. `GET /api/v1/operator/digest` повернув `operator-digest` і три імені полів, без чисел угод. Це маршрут з краш-тесту ЛР10.

`POST /auth/api/v1/auth/login` без процесу Authentication дає 502 з порожнім тілом. Так відповідає YARP, коли кластер недоступний. JSON із `title` і `detail` пише обробник винятків, і для цього логіну він не викликається. 400 і 401 описані за валідатором і обробником Authentication. Живий процес Authentication під час перевірки не працював, тож ці два коди зняті з коду, не з curl.

Конвеєр не випускає документацію зі зламаним посиланням. Коміт `a254377` додає посилання на `missing-page.md`. Крок `mkdocs build --strict` падає, анотація — `Process completed with exit code 1`. Коміт `96d2bf4` посилання прибирає, той самий крок зелений. Прострочена сторінка зі статусом `deprecated` у звіті аудиту є і збірку не валить. Прострочений `published` звалив би. Тег `docs-v1.0` стоїть на зеленому коміті `96d2bf4`.

Далі з кореня, у двох вікнах: `dotnet run --project Gateway/src/Relativa.Gateway/Relativa.Gateway.csproj` і `mkdocs serve`. У браузері відкрити `http://127.0.0.1:8000/Relativa/api/`, Try it out на `GET /health`. Для виклику з цього порту процес треба стартувати з `Cors__AllowAnyOriginForDev=true`. У репозиторії прапор лишається вимкненим.
