# Контракт API

Інтерактивна довідка нижче зібрана з файлу [openapi.yaml](openapi.yaml). Окремої таблиці маршрутів на цій сторінці немає: інакше версія і форма відповіді розійшлися б із контрактом.

Версія контракту — поле `info.version` у тій самій специфікації. Зараз це `1.0.0`.
