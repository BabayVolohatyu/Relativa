# База знань Relativa

Ця сторінка відповідає на питання «куди йти далі». Призначення продукту і команди запуску в один абзац тут не повторюються: вони живуть у кореневому `README.md`.

| Рівень | Питання | Де читати |
|---|---|---|
| 1. README | Що це і як запустити за п'ять хвилин? | Файл `README.md` у корені репозиторію |
| 2. Розробнику | Як приєднатися до розробки? | [Огляд для розробника](developer/index.md) |
| 3. API | Як інтегруватися? | [Контракт OpenAPI](api/index.md) |
| 4. Архітектура | Чому система влаштована так? | [SDD, ISD, ADR](architecture/index.md) |

Дата внизу сторінки на зібраному сайті ставиться плагіном `git-revision-date-localized` з історії Git, не вручну.
