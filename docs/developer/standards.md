# Стандарти коду

Поріг з ЛР1, який вже стоїть у `.githooks/pre-commit`:

- метод C# із цикломатичною складністю вище 10 коміт не проходить;
- gitleaks зупиняє коміт, якщо в індексі є секрет;
- каталоги `Migrations`, `bin`, `obj` і файли `*.Designer.cs` гачок складності не міряє.

Друге правило, з ЛР10: зміна публічної поведінки оновлює документ у тому самому pull request. Список файлів — у [чек-листі](contributing.md).

Глибокі нотатки шарів .NET лишаються в `docs/ai-guides/`. У зібраний сайт вони не входять, щоб не було другої архітектурної розповіді поруч із [SDD](../architecture/sdd.md).
